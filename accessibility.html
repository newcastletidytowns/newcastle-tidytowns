Accessibility

Making this site work for everyone.

We want the Newcastle Tidy Towns website to work well for everyone, whatever device or setup they use.

This statement applies to the website at newcastlecodublintidytowns.ie. We aim to meet the WCAG 2.1 AA accessibility standard.

What we do to help

This website has been built to:

  • use clear, readable text with strong colour contrast;
  • work when navigating by keyboard, with a visible focus outline;
  • offer a "skip to main content" link for keyboard and screen-reader users;
  • use proper headings and page structure so screen readers can follow along;
  • include text descriptions for meaningful images;
  • resize and reflow cleanly on phones, tablets and computers.

Areas we're still improving

We're only a small group of volunteers, so we keep improving things as we go. If you find any part of the site hard to use, please let us know and we'll do our best to sort it.

Tell us about a problem

If any part of the site gives you trouble, or you need something in a different format, just get in touch and we'll help however we can:

hello@newcastlecodublintidytowns.ie

We aim to reply within a few days.

Thanks for letting us know.

Every bit of feedback helps us make the site better for everyone in the village.
